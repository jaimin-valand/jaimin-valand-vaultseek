# v2.6 - Consensus & Leader Election

v2.6 adds a deterministic, in-process Raft-style consensus model for portfolio and testing purposes.

## Capabilities
- leader election with monotonically increasing terms
- majority-based log replication
- majority commit and apply tracking
- leader failure and re-election
- follower catch-up
- state digests for deterministic replication checks
- explicit quorum failures

This is an educational consensus model, not a claim of production-ready Raft or linearizability. Real deployments require network transport, persistent consensus state, randomized election timers, membership changes, snapshots, and extensive adversarial testing.
