# v2.7 - Consensus Persistence & Network Fault Injection

v2.7 hardens the educational Raft-style layer with durable node state and a deterministic network-fault model.

## Persistence

`ConsensusPersistence` atomically stores term, vote, commit index and replicated log entries. Recovery ignores missing state and reconstructs typed log entries from JSON.

## Fault model

`NetworkFaultInjector` can deterministically drop or partition traffic between nodes and heal the network. Events are recorded for reproducible tests.

## Boundary

This remains an educational/in-process consensus model. It is not a production Raft implementation: transport, randomized elections, snapshots, membership changes and formal linearizability testing remain future work.
