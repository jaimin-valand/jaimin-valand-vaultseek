# v2.0 Architecture

Private Search Engine 2.0 adds three systems capabilities: variable-byte delta compression primitives, an append-only write-ahead log for recoverable index mutations, and deterministic local hybrid retrieval.

## Compression
Posting/document identifiers can be represented as sorted delta gaps and encoded with variable-byte integers. This reduces integer-stream storage while retaining fast sequential decoding.

## WAL
Index mutations are appended before the in-memory/index-store update. The WAL is fsync'd on append and can be inspected/replayed by future recovery tooling. Checkpointing clears committed records.

## Hybrid retrieval
The default retrieval path combines lexical BM25/field-aware scores with a deterministic feature-hashing semantic proxy. It requires no external model, credentials, or network calls.

This semantic layer is intentionally a local baseline; it is not presented as equivalent to a transformer embedding model.
