# v2.2 - Sharded Distributed Search

## Goals

- Deterministic document-to-shard assignment.
- Parallel query fan-out.
- Global top-K merge.
- Per-shard statistics.
- Persistent shard snapshots.
- Offline reproducibility without external services.

## Sharding

A document is assigned using SHA-256(doc_id) modulo the configured shard count. This avoids Python's process-randomised `hash()` and makes assignments stable across restarts.

## Query fan-out

The coordinator submits the same query to each shard using a bounded `ThreadPoolExecutor`. Each shard returns more than the requested K results so the coordinator has enough candidates for a global merge.

## Global merge

Results are sorted by descending score and then `doc_id` as a deterministic tie-breaker. The coordinator returns the global top-K results.

## Scope

This is a distributed-search architecture simulator rather than a networked cluster. The next distributed milestone can introduce remote shard nodes, RPC timeouts, partial-failure handling and shard-level health checks.
